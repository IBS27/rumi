Rumi's substance is measured geometry, so the interface borrows the conventions of an architectural plan: section-cut walls, dimension lines with ticks, a half-metre grid under the drawing, and rules that separate data the way title-block cells do. The plan itself is the same drawing on every screen, with the selected object or the fit problem marked in red pencil. IBM Plex Sans is the only typeface. Ink #1C2B3A on grey-blue paper #E8EDF1 and sheet #F7F9FB; red pencil #D0441C is reserved for the selected object and warnings.
